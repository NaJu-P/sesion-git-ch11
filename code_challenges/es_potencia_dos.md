# Es Potencia De Dos
## ¿Que entendí?
## Tenía que validar por false o true si era potencia elevado por 2 y tenia que utilizar la función def is_power_of_two(n: int) -> bool para poder validarlo.
## ¿Como lo resolvi?
## Cree una lista con posibles resultados elevado a 2 llamada resultados y después los devuelvo con la función return, al mismo tiempo utilizando la variable de la función "n" y evaluarlo si estaba en la lista por false o true.
## ¿Qué aprendí?
## Aprendí con la función return que se puede utilizar otras palabras reservadas como el in o utilizarlo como si fuera un for, además que la función y en sus parámetros exige un tipo dato para entregar.
