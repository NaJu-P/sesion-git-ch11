# ¿Es Divisible?
## ¿Que entendí?
Debia usar los parametros value y divisor para encontrar si era divisible y devolver un bool al final de la respuesta.
## ¿Como lo resolvi?
Use la operación % para hallar el resido de 0 porque si el resultado me daba 0 significa que es divisible, y usando esta formula lo compare con un if si el resido era 0 retorna True sino entregaba False.
## ¿Qué aprendí?
Aprendí a utilizar la operación de resido directa en un if.
